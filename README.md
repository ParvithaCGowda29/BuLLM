# BuLLM

One repo, three apps, each self-contained in its folder with its own package.json:

- **BAM_UI/** - the BAM workbench (from the BAM_UI repo, main branch)
- **BuLLMind_Masters/** - the Masters app (from the BuLLMind_Masters repo, main branch)
- **Admin/** - the Admin app (from the Admin repo, main branch)

Each app runs on its own, same as before: `cd <folder> && npm install && npm run dev`.
Each app's full commit history is preserved in this repo.
